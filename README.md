# Muhammad Muslim Cybersecurity Portfolio

Production implementation for `https://muslimaamir72.github.io/`.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run check
```

## Deployment boundary

This local repository is connected to `https://github.com/muslimaamir72/muslimaamir72.github.io`. GitHub Pages must not be enabled until the reviewed build is separately approved for publication.
